# Published social assets

Final, upload-ready renders committed so schedulers (Metricool) and any other
tool that needs a public URL can fetch them. Everything here is already public
by intent — it is what gets posted.

`social/out/` stays gitignored; only what is actually scheduled lands here, in a
dated folder.

Raw URL pattern:

```
https://raw.githubusercontent.com/eunbitjang/hungry-worms/master/social/publish/<folder>/<file>.png
```
